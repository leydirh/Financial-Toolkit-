## How to View Locally
Simply double-click `index.html` in your file explorer to open the website in Chrome, Edge, or any modern browser!

## How to Deploy to Replit / Carrd / Vercel / GitHub Pages
- **Replit**: Create an HTML/CSS/JS repl, drag and drop `index.html`, `styles.css`, and `app.js`, and click **Run**.
- **GitHub Pages**: Upload the files to a repository and enable Pages in repository settings.
- **Vercel / Netlify**: Drag & drop the `Rays_Financial_Toolkit` folder into Vercel/Netlify dashboard for instant live deployment!
